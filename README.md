# Prueba Técnica - Analista de Datos (LikeU)

Este repositorio contiene el desarrollo del caso práctico para el proceso de selección en LikeU. El proyecto abarca un flujo completo de datos: extracción, transformación y carga (ETL), análisis estructurado y visualización de resultados.

## 🛠️ Herramientas y Tecnologías Utilizadas
* **Python:** Limpieza, procesamiento de datos y automatización del ETL.
* **SQL:** Análisis y consultas estructuradas sobre bases de datos relacionales.
* **Power BI:** Diseño de dashboard interactivo para el monitoreo de métricas.
